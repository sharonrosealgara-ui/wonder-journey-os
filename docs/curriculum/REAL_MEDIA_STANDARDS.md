# REAL MEDIA STANDARDS

## Factual Media Rules
- **Use real photographs for:** destinations, historical places, food, cooking tools, animals, plants, clothing, transportation, homes, markets, cities, schools, landscapes.
- **Do not use** fabricated AI images or emojis as factual evidence.
- Missing factual assets must display: `Real image pending verification`

## Allowed Illustrations
- Maps, timelines, diagrams, flash cards, game boards, decorative elements.

## Visual Style
- Premium children's storybook, Canva-style full-screen, tropical watercolor accents, scrapbook aesthetics.
- Warm colors, large rounded typography.
- Respect prefers-reduced-motion.

## Component Architecture
- Single centralized factual-media registry.
- Metadata: descriptive alt text, factual caption, source/attribution, aspect-ratio handling, loading/error states.
- No broken-image icons. No invented captions.
